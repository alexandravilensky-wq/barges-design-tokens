# Barges design tokens

Figma variables → `tokens/*.json` → **Style Dictionary** → `build/css/<brand>.css` → this Storybook.

Use the **Brand** and **Theme** menus in the toolbar to switch between Purple Garden, Kasamba, Psiquicos and
Purple Ocean in light or dark mode. Every page is drawn with the generated CSS variables, so what you see is exactly
what a consuming app gets.

## Updating tokens

1. Export the variables from Figma into `tokens/` and commit.
2. `npm run storybook` rebuilds the CSS (`npm run build:tokens`) and starts Storybook.

The build prints any Figma alias that points at a variable outside the export. Those get a stand-in value from
`config/unresolved-fallbacks.json` until they are fixed in Figma.

## Using the CSS

```html
<link rel="stylesheet" href="build/css/purple-garden.css" />
<html data-theme="dark"> <!-- omit for light -->
```

```css
.button { background: var(--color-button-primary-default); border-radius: var(--radius-button); }
```

Text styles are classes: `<h1 class="text-display-large-emphasis">`.

## Icons

Icons come from the Figma DS-Foundation file (**Icons & Images** page), not from the token export.

1. Publish the Foundation library in Figma (see **Icons › How to add an icon**).
2. Every night the **Export icons** GitHub Action exports every icon as SVG and, if anything changed, opens a pull
   request with a plain-language summary and a list of things to fix in Figma. It can also be run by hand from the
   Actions tab.
3. Review the SVG diff and the **Icons** page here, then merge.

Output: `icons/<brand>/<code-name>.svg` and `icons/icons.json` (Figma name, code name, old names, files per brand).
Single-colour icons use `currentColor`; colour them with their token:

```css
.icon { color: var(--color-icon-primary); }
```

Run it locally with `FIGMA_TOKEN=… npm run export:icons`. The Action needs a `FIGMA_TOKEN` repository secret
(a Figma personal access token with read access to the file).
