# Fonts

Storybook loads Google Fonts for Literata, Fraunces, Work Sans, Inter and Fira Sans.

**ABC Social** (Purple Garden) is licensed, so it isn't in git. To preview it locally, copy the font files into
`fonts/licensed/` (git-ignored):

- `ABCSocial-Regular.otf` (400)
- `ABCSocial-Medium.otf` (500)

Without them, Storybook shows ABC Social as "fallback shown" and uses system-ui.
